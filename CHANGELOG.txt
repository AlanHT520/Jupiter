================================================================================
  Jupiter v-0.8.5 — Changelog(对比v-0.7.9)
  2026-10-07
================================================================================

一、PC 端 (JavaFX) 修复
--------------------------------------------------------------------------------
  [1] 报表导出重构为全量聚合模式
      - 之前：只能选择单个任务导出报表
      - 之后：自动拉取所有已完成任务，按任务日期倒序合并，
        每个学生只保留最新一条查寝记录，生成包含所有查宿信息的完整报表
  [2] 移除导出前的任务选择对话框，点击导出后直接选择目录即可
  [3] 登录页标题由单行 "Jupiter Java Edition" 拆分为上下两行：
      Jupiter（38px 蓝色粗体）+ Java Edition（16px 蓝色细体）
  [4] 启动闪屏 (SplashPreloader) 标题同步分层为三行
  [5] 窗口标题统一

二、后端 (Spring Boot) 修复
--------------------------------------------------------------------------------
  [6] CheckRecordRepository 新增 findByTaskIdIn() 支持跨任务批量查询
  [7] TaskRepository 新增 findCompletedTasks() 按日期倒序获取已完成任务
  [8] StatisticsService 新增 generateAggregatedReport()
      聚合所有已完成任务，支持按任务日期去重取最新记录
  [9] ReportQueryService 新增 generateAggregatedReport(ReportType, targetId)
      支持全量楼栋报表、学院报表、班级报表三类
  [10] ExportReportService 支持 taskId=null 时自动切换全量模式
  [11] ReportExportBundleService 支持 allTasks 模式，
       一次导出包含学院汇总、全楼栋汇总、各楼栋明细、各班级明细

三、Android 端修复
--------------------------------------------------------------------------------
  [12] JSON 注入漏洞修复：TcpClient.submitCheck() 改用 buildJsonObject 安全构造
  [13] 主线程阻塞修复：MainActivity 中 runBlocking 改为 LaunchedEffect 异步执行
  [14] Token 改用 EncryptedSharedPreferences 加密存储
  [15] 网络请求添加指数退避重试机制（最多 3 次）
  [16] 离线查寝提交缓存到 Room 数据库，联网后自动同步
  [17] 任务列表添加下拉刷新 (pullToRefresh + SwipeRefresh)
  [18] 图片上传前自动压缩到 1024px 以内
  [19] Back 键添加二次确认防止误退出
  [20] 查寝状态选择添加高亮边框和颜色标记视觉反馈
  [21] 学生列表搜索改为大小写不敏感
  [22] Session 过期时弹出提示并自动跳转到登录页
  [23] 暗色主题跟随系统设置自动切换

四、UI / 体验改进
--------------------------------------------------------------------------------
  [24] PC 登录页优化
  [25] 启动闪屏同步品牌分层设计
  [26] PC 端窗口标题统一含版本号
  [27] 项目PC版本号与 Android versionName 统一

五、新增数据层方法
--------------------------------------------------------------------------------
  [28] CheckRecordRepository.findByTaskIdIn(List<String>)
  [29] TaskRepository.findCompletedTasks(TaskStatus)
  [30] StatisticsService.generateAggregatedReport()
  [31] ReportQueryService.generateAggregatedReport(ReportType, String)
  [32] ExportReportService 空 taskId 聚合模式
  [33] ReportExportBundleService 全量导出分支
